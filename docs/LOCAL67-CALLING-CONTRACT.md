执行对象为配置中当前MapGIS6.7安装及其实际功能。功能发现以实际主菜单/模块、原厂SDK、安装帮助与运行观察为准。跨版本或独立专业产品、额外找矿/资源业务模型不因调研提及而进入完成条件。已安装组件是否由这套6.7直接提供以实际启动器/菜单核对，不按产品宣传扩展。

需要交付的调用能力：

1. Agent发现实际模块和功能入口，读取参数/前置条件。
2. Agent通过既有SDK/文件接口或现有受控Sky界面入口执行操作。缺少SDK时优先接通原厂操作，不重写无关专业算法。
3. 自动输入明确的任务参数，完成原厂运算/编辑、保存、导出并读回结果。
4. 执行与失败状态能读回；可恢复结果先对账，不盲目重复。
5. 只在任务副本和自有进程中验证，保留原始数据、安装、许可、其他会话与回滚记录。
6. 提供可使用的完整调用入口与包，并列明确证的本机运行条件/限制。静态菜单数量、工具数量或某个算法通过均不能冒充全部功能执行验收。

用户要求的是可调用能力。已有专用接口能完成的任务直接复用；其余可由通用原厂调用机制覆盖。验证调用机制、实际模块和必要保存/重开流程，不把每种参数组合、每个专业算法的科研性能或新机器部署自动升级为完成条件。MCP与现有正式CLI为两种已存在的调用入口；当前客户端连接暂时失效时，可用同一工具注册表的CLI完成已授权调用，不因此修改其他会话、provider或安全边界。
