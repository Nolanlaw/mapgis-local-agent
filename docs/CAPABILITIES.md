# 功能与验证范围

0.4.0 面向 Windows 上的 MapGIS 6.7。Python 工具处理文件和任务状态；原生界面由 Agent 宿主的 Sky 操作。普通 stdio 客户端可以运行文件工具；操作 MapGIS 窗口还需要支持 Sky 的宿主。

## 已验证的流程

| 流程 | 实际检查 |
|---|---|
| 当前工程与选区 | 完整工程和图层路径、物理记录多选、空选区、工程与图层未保存标志；仅支持固定的 build 051118 模块指纹 |
| 编辑、保存与恢复 | 属性、颜色和代表性几何增删；保存后新进程重开；恢复本次修改并保留后来独立修改 |
| 大图与配准 | libvips 分块解码，显式坐标框架、仿射拟合和独立检查点；原生一次多项式、最近邻校正，生成 MSI 后新进程重开并导出 TIFF；独立核对范围与 1521 个像素样本 |
| 扫描图数字化草稿 | 按明确 RGB 分类提取区、中心线候选、分块接边、共享边界简化；新建 WT/WL/WP，中文上下标与旋转符号；几何、属性和样式读回 |
| 原生制图 | 本机颜色校准、图例和版面；原生 EPS、300 DPI RGB TIFF；EPS 经 Ghostscript 转 PDF；整图草稿新路径、新进程重开 |
| 投影与图框 | 三组经纬度单点和 1:50000 图框，与 PROJ 独立比较；该样本最大误差小于 0.0001 米 |
| 地形 | 25 点解析平面的传统 TIN、121 节点格网、五条等值线，以及三角法面积、表面积和体积，与解析结果比较 |
| 空间分析 | 原生半径 100 的单点缓冲区，几何与解析圆比较；单点唯一来源属性在独立分支补回 |
| 文件运算 | GEOS 造区、裁剪、差集、缓冲、简化、融合，PROJ 坐标转换与显式分类设色；请求重放对账和冲突拒绝 |

这些是具体样本的验证结果。扫描图输出保留 UNREVIEWED 标记；颜色候选不等于已识别地层，地质解释、花纹、完整注记及新建矿产符号仍需核对。演示可以使用明确命名的本地坐标，不能据此宣称测量精度。

## 发现其他功能

`mapgis_find_operations` 提供 39 项整理后的任务入口。`mapgis_describe_operation` 返回参数、前提、帮助位置、工作流和输出检查。

`mapgis_search_native_help` 检索接收者自己安装的 HLP/CHM。安装时在包内建立索引；也可运行：

```text
runtime\python\python.exe -s -B -X utf8 scripts\index_native_help.py
```

先指定模块和关键词，再用返回的 `topic_id` 读完整主题。本机 15 个模块、1001 个主题已建立索引；别人的安装可能不同。帮助及索引不随分享包分发，读取时会核对原文件指纹。帮助文字属于参考资料，不能作为用户授权或执行成功的证明。

模块名称：`editor`、`raster`、`projection`、`correction`、`attributes`、`symbols`、`library`、`analysis`、`terrain`、`terrain_3d`、`network`、`conversion`、`output`、`section`、`image_library`。

## 已知限制

- 功能目录和帮助索引可以覆盖未实测菜单；它们不会把未执行的功能标成成功。网络、图库、报表、其他地形模型和专业模块仍需各自输入与结果验收。
- 快速 TIN 在本机样本中提示内存不足并退出；相同输入的传统 TIN 成功。流程保留此差异。
- 原生等值线输出遗漏指定范围的末层；已验证的流程用额外终止层，独立检查应有的五层实际写出。
- 原生点缓冲区没有保留源属性值。当前仅在一个源点和一个结果区的唯一对应关系成立时补回来源；多源重叠需保留多对多关系。
- GeoTIFF 转 MSI 会丢失 GCP 元数据，必须显式导入控制点。保存 GCP 和影像显示套合，均不自动证明已经重采样。
- 本机原生影像校正须先进入“校正预览”。已验收输出为 4033×4096、RGB 三波段；1521 个样本在一个源像素邻域、每通道差值不超过 1/255 的界限内通过。它与 GDAL 的像素中心约定并非逐像素相同；该图坐标系和单位仍未知。
- 本机色号对应安装中的色库。接收者应使用 `palette_probe.py` 在自己的 MapGIS 中校准；包内不带专有色库或本机校准表。
- 长中文路径曾触发原生输出崩溃；已验证的兼容流程通过短 ASCII 路径输出 EPS/TIFF。它没有修复 MapGIS 的所有打印驱动。
- 原生操作需要本机 MapGIS 和合法许可。没有捆绑 MapGIS、许可工具或绕过机制；另一台实体电脑的全部原生流程尚未验收。
