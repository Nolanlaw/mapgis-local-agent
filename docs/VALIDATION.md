# 验证记录

## 0.5.0 后台增量（2026-10-29）

在固定的 MapGIS 6.7 build 051118 组件上完成，使用独立 x86 进程；没有前台输入、编辑器注入或原程序修改。

- 同一加载探针对照：默认 DEP 进程在 BAS60 初始化时因执行不可执行私有内存失败；只改变新宿主的 NXCOMPAT 构建标记后加载成功。Windows 策略不变。
- 原生文件流程：WT/WL/WP 读取、另存后由新 PID 重开；多点坐标更新，WT/WL 删除，独立几何/属性/样式比较和字节恢复。失败、重复请求及保存前来源变化均保留检查。
- 原生出图：从 winout60 创建 EPS，通过 mapdsp60 绘制实际工作区，设置页幅和坐标变换。区使用实际几何绘制结果；不把整层函数返回成功当作已画出图形。
- 独立 Ghostscript 解释 EPS，检查头尾、物理页幅、像素尺寸与可见内容。合成多图层测试明确要求有区填充，避免只剩点线的输出通过。
- 现有扫描图草稿的 4 图层实际后台出图：352区、1891线、3个产状符号、36条注记；220×220 mm，624×624 的72 DPI检查预览，240005个非白像素。逐一核对输入指纹；保留 UNREVIEWED 的地质与坐标精度范围。

这些结果建立后台文件和 EPS 通道。其他构建、其他实体电脑、尚未保存的编辑器内存、WP 拓扑删除和全部专业模块的后台调用仍需各自验收。现有桌面验证不因此转换为后台验证。


版本：0.4.0。环境：Windows x64，MapGIS 6.7 build 051118。功能目录及帮助索引不代表对应原生操作全部验收。

## 原生样本

- 当前工程、完整图层路径、真实多选/空选区、工程与图层未保存状态。属性和颜色保存后新进程重开；几何新增再删除；结构恢复保留后来独立修改。
- 扫描图建立新的点线区草稿，校准本机色号、中文文字、旋转符号、图例与版面；实际原生 EPS、300 DPI RGB TIFF 和 EPS 转 PDF；工程移到新路径后新进程重开，核对五个依赖。
- 原生影像一次多项式、最近邻校正，输出新的 MSI。关闭原进程，在新进程重开，再从 MapGIS 导出 RGB TIFF。实际尺寸 4033×4096；范围误差小于 0.00001 本地坐标单位。1521 个样本均在一个源像素邻域、每通道差值不超过 1/255 的界限内通过；其中 1501 个与邻域像素 RGB 完全相同。未证明与 GDAL 重采样逐像素一致。
- 三组投影点和 1:50000 图框，对照 PROJ；传统 TIN、121 节点格网、五层等值线、三角法面积/表面积/体积，对照解析平面；单点缓冲区对照解析圆。

原生 MSI 打开时会独占文件；转换前先正常关闭图像。导入 GCP 会追加现有控制点，不能把追加后的冲突点用于校正。快速 TIN 的失败、等值线末层遗漏及缓冲属性丢失均保留为已知差异，具体处理见 [CAPABILITIES.md](CAPABILITIES.md)。

测试数据不随仓库分发。每个原生样本的输入参数、独立结果比较和限制汇总于 [CAPABILITIES.md](CAPABILITIES.md)。

尚未验证另一台实体电脑的全部原生流程；扫描图的地质解释、完整花纹和注记仍待复核；网络、图库、报表及其他专业模块没有被这些代表性样本覆盖。
