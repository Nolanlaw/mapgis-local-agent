# 验证情况

## 0.3.2 分享包

- 包内 `README.md` 与新版使用指南一致；包版本和程序内部版本号均为 0.3.2。
- 38 项 Python 测试、14 项 Node 测试通过。
- 实际解压并校验了 8,830 个文件；其余运行依赖沿用 0.3.1 的已验证文件。
- 使用合成线文件检查了九个 MCP 工具、修改、请求对账、取消和逐字节恢复，原文件保持不变。
- 在中文和空格路径下验证了安装、文件夹迁移、客户端配置、版本匹配提示及 EPS 转 PDF。

测试使用包内 Python，禁用了用户目录中的 Python 包，并将 `PYTHONHOME` 和 `PYTHONPATH` 指向无效目录；这不是整机物理断网测试。

## MapGIS 原生流程

此前在本机 MapGIS 6.7 build 051118 上验证了 56 区多选及取消、工程与图层未保存状态、几何复制和删除、保存后新进程重开，以及原生 EPS/TIFF 出图。恢复测试还检查了保留后续独立修改。

0.3.2 更新说明和版本号，没有重新执行这些原生界面操作。

## 使用边界

- `MATCH` 表示 MapGIS 模块指纹匹配；许可和 Agent 宿主的电脑操作能力需分别确认。
- 原生出图使用短 ASCII 暂存路径，并检查工程依赖和实际输出文件。
- 测试图件用于技术验收，坐标系、比例尺和地质解释需要针对实际项目核对。
- 其他实体电脑上的完整原生流程尚未测试。

原始测试日志留在本机。分享包中的 `bundle-manifest.json` 可用于逐文件校验。
